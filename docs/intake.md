# Intake Template

Use this template to capture requirements and constraints before starting implementation.

## Goal

**What are we trying to achieve?**
- [ ] Clear, single-sentence goal
- [ ] Business value explained
- [ ] Success metrics defined

## Constraints

**What are the hard limits?**
- [ ] Technical constraints (languages, frameworks, versions)
- [ ] Time constraints (deadlines, milestones)
- [ ] Resource constraints (team size, budget)
- [ ] Security constraints (compliance, audit requirements)
- [ ] Performance constraints (latency, throughput)
- [ ] Compatibility constraints (browsers, chains, platforms)

## Non-Goals

**What are we explicitly NOT doing?**
- [ ] Out of scope items listed
- [ ] Future work documented
- [ ] Known limitations acknowledged

## Risks

**What could go wrong?**
- [ ] Security risks identified
- [ ] Technical risks (complexity, dependencies)
- [ ] Operational risks (deployment, rollback)
- [ ] Business risks (timeline, scope creep)
- [ ] Mitigation strategies defined

## Acceptance Criteria

**How do we know it's done?**
- [ ] Functional requirements listed
- [ ] Non-functional requirements (performance, security)
- [ ] Edge cases considered
- [ ] User experience requirements
- [ ] Measurable success criteria

## Test Plan

**How will we verify it works?**
- [ ] Unit test coverage target
- [ ] Integration test scenarios
- [ ] E2E test scenarios (if UI)
- [ ] Security test scenarios
- [ ] Performance test scenarios
- [ ] Manual test checklist
- [ ] Regression test plan

## Rollout Plan

**How will we deploy this?**
- [ ] Deployment strategy (blue-green, canary, etc.)
- [ ] Rollback plan
- [ ] Monitoring and alerting
- [ ] Feature flags (if applicable)
- [ ] Gradual rollout plan
- [ ] Communication plan

## Dependencies

**What do we need?**
- [ ] External dependencies listed
- [ ] Internal dependencies (other teams, services)
- [ ] Data dependencies
- [ ] Infrastructure dependencies
- [ ] Timeline dependencies

## Open Questions

**What needs clarification?**
- [ ] Technical questions
- [ ] Business questions
- [ ] Design questions
- [ ] Timeline questions

## Next Steps

- [ ] Intake reviewed and approved
- [ ] Technical plan created (see `technical-plan.md`)
- [ ] Implementation started
- [ ] Verification scheduled
