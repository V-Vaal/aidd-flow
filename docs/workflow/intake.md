# Intake Phase

Capture requirements, constraints, risks, and acceptance criteria before planning.

## Summary

- Prompt: `prompts/intake.md`
- Output: `aidd/work/INTAKE.md`

**INTAKE should include:**
- Goal, scope, and non-goals
- Constraints and risks
- Acceptance criteria
- Test and verification expectations

See the full template requirements in `docs/quality/intake.md`.
