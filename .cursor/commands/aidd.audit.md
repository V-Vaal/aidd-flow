# AIDD Audit Command

## Purpose

Perform a comprehensive audit of the repository to understand its current state, architecture, risks, and opportunities for improvement.

## Usage

1. **Read the canonical prompt**: Open and follow `.cursor/prompts/audit.md`
2. **Produce the artifact**: Create or update `.cursor/work/AUDIT.md` following the prompt's procedure

## Quick Reference

- **Prompt**: `.cursor/prompts/audit.md`
- **Output**: `.cursor/work/AUDIT.md`

This audit phase is part of the AIDD workflow. After completing the audit:

- Update `.cursor/memory/activeContext.md` if significant insights are discovered
