# Compact Response Template

Use this template to minimize token usage while preserving actionability.

## Default output order

1. Findings / result
2. Critical risks or blockers
3. Validation evidence
4. Next actions (only if needed)

## Style constraints

- Findings-first
- No repeated context
- No long prose intros
- Avoid quoting large file content
- Prefer bullet points over paragraphs

## Example skeleton

```markdown
## Result
- ...

## Risks
- ...

## Validation
- Command: ...
- Outcome: ...

## Next
1. ...
```
