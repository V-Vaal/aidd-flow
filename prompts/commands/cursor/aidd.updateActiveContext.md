# AIDD Update Active Context Command

## Purpose

Update the activeContext.md file in the Memory Bank to reflect completed work, current system state, next steps, and open questions. This is a mandatory post-flight step in the AIDD workflow.

## Usage

1. **Read current activeContext.md**: Review `.cursor/memory/activeContext.md`
2. **Update sections**:
   - Last completed task (what was done, date, reference to INTAKE/PLAN/REVIEW)
   - Current focus (what is being worked on now, or mark complete)
   - Next steps (immediate next steps, prioritized)
   - Recent changes (add entry with date, description, files modified, link to REVIEW.md)
   - Active decisions (decisions made, rationale)
   - Important patterns and preferences (new patterns, preferences)
   - Learnings and insights (new learnings, discoveries)
   - Current challenges (ongoing challenges, blockers)
   - Open questions (unresolved questions, areas requiring investigation)
   - Notes (additional context, observations)
3. **Save**: Update `.cursor/memory/activeContext.md`

## Quick Reference

- **File**: `.cursor/memory/activeContext.md`

## Master Workflow Reminder

- This update is **MANDATORY** after any successful modification
- The master workflow rule requires activeContext.md to be updated post-flight
- Keep this file accurate for continuity across AI-assisted sessions
- This file is included in context bundles generated by `aidd-context.sh`
